# 📅 ScheduleWidget

Windows 바탕화면에 붙여 쓰는 D-day 일정 위젯입니다. 주간 달력·음악 막대·캐릭터를 보여 주는 **달력 창**(코드의 `MiniWindow`)이 메인 화면이고, 머리띠의 체크리스트 버튼으로 **일정 목록 창**(TODO 창)을 옆에 열어 함께 사용합니다. 두 창은 같은 일정 데이터를 공유하고 `Win + D`를 눌러도 남습니다. 기본값에서는 일반 앱처럼 클릭하면 앞으로 올라오고 다른 앱을 쓰면 뒤로 가며, 설정의 `모든 창 위에 표시 (일정 창·미니 창)`를 켜면 항상 위에 고정됩니다.

## 주요 기능

- **일정**: 추가·수정·삭제, 완료 표시, D-day 계산, 선택적 시간 지정, 카드별 색상.
- **미니 창**: 1~7일 달력(한국 공휴일, 일정 블록, 블록 D-day), 테마 5종(Light·Dark·Blue·Pink·Modern), 음악 조작 막대, 최대 3마리의 캐릭터.
- **캐릭터**: 기본 캐릭터 4종(흰·검은·파란·빨간 모찌, 앱에 포함), OpenAI Codex가 설치되어 있으면 Codex 캐릭터 9종(앱에 포함하지 않고 설치된 Codex에서 가져옴), 이미지·GIF·Codex `pet.json`·내보낸 `.zip` 가져오기, 캐릭터별 동작·크기·위치와 마지막 자리 기억.
- **음악**: 음악 파일과 YouTube 링크를 섞은 플레이리스트, 그리고 브라우저·Spotify 등 다른 앱에서 재생 중인 미디어까지 미니 창 막대로 조작.
- **연락과 알림**: 텔레그램·카카오톡 메시지, PC·텔레그램·카카오톡 마감 알림, Windows ‘휴대폰과 연결’ 열기.
- **구글 연동**: 로그인 후 ON/OFF 스위치로 구글 캘린더와 일정을 양방향으로 맞추고, 가져온 캐릭터를 구글 드라이브에 보관.
- **Windows 연동**: 트레이 아이콘, 로그인 시 자동 시작, 중복 실행 방지, 모니터별 창 위치, 전역 단축키(기본 `Ctrl+G`)로 맨 앞에 띄우기.

## 요구 사항

- Windows 10 / 11, .NET Framework 4.7.2
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/): 캐릭터 표시(미니 창, `캐릭터 선택`)와 YouTube 재생에 필요합니다. 없으면 캐릭터 자리에 설치를 확인하라는 안내가 나옵니다.
- 인터넷 연결은 구글 연동, YouTube 링크 추가·재생, 텔레그램·카카오톡 전송에만 필요합니다.

## 기본 사용법

### 시작과 종료

- `ScheduleWidget.exe`를 실행하면 트레이에 아이콘(`일정 위젯`)이 생기고 달력 창이 열립니다. 이전 버전에서 일정 목록 모드로 종료했어도 달력으로 시작합니다. 목록은 체크리스트 버튼으로 필요할 때 엽니다.
- 이미 실행 중이면 “프로그램이 이미 실행 중입니다.” 안내만 띄우고 새로 실행한 프로그램은 종료합니다. 중복 실행 방지 방식이 다른 예전 버전과도 서로 막아, 어느 쪽이 먼저 실행 중이든 나중에 실행한 쪽은 시작하지 않습니다(이 버전이 나중이면 이 안내를 띄우고 종료합니다).
- 처음 실행하면 `Windows 시작`이 켜져 있어 다음 로그인부터 자동으로 시작합니다(설정에서 끕니다).
- 일정 목록 오른쪽 위 `X`는 목록만 닫습니다. 프로그램 종료는 달력·목록의 우클릭 메뉴 또는 트레이 메뉴의 `종료`를 사용합니다. `Esc`는 창을 숨길 뿐 프로그램은 트레이에서 계속 실행됩니다.
- 원본 창에서 `Alt+F4`를 눌러도 `Esc`처럼 창만 트레이로 숨기고 프로그램은 계속 실행됩니다.
- 예상 밖의 오류는 `%LocalAppData%\ScheduleWidget\error-log.txt`에 기록합니다(시각·발생 위치 `ui`/`background`/`task`/`load`·오류 내용, 64KB를 넘으면 이전 내용은 `error-log.old.txt`로 바뀝니다). `load`는 일정 파일을 읽지 못했을 때입니다.
- 화면 쪽 오류는 시작을 끝낸 뒤에는 그 동작만 실패하고 앱은 계속 실행되며, 1분에 20번을 넘게 반복되거나 시작하는 중에 나면 기록 파일 위치와 함께 안내를 띄우고 종료합니다.

### 일정 추가와 관리

- **추가**: 아래쪽 입력줄에 제목을 쓰고 년·월·일(또는 달력 아이콘)을 고른 뒤 `추가`를 누릅니다(제목 칸에서 `Enter`도 같습니다). `시간 지정`을 켜면 `H:mm` 또는 `HH:mm`으로 시각을 넣을 수 있고 `HH:mm`으로 저장됩니다. 켜지 않으면 날짜만 있는 일정입니다.
- **목록**: 날짜 순입니다(오래된 지난 일정이 맨 위, 먼 미래 일정이 맨 아래). 같은 날은 시간 순(시간 없는 일정은 뒤), 그다음 제목 순이고, 날짜를 읽을 수 없는 일정(`날짜 확인`)은 맨 뒤입니다. 카드 오른쪽에 `D-3`·`D-day`·`D+2`가 표시되고(완료하면 `완료`) 오늘·예정·지난 일정의 글자색이 다릅니다.
- **카드 우클릭 메뉴**: `수정`(제목·날짜·시간을 고치는 `일정 수정` 패널), `완료 / 미완료`, `카드 색상 선택`, `기본 색상으로`, `이 일정 보내기`(`연락 · 알림`의 메시지 칸에 내용을 채웁니다), `삭제`, `종료`입니다. 카드 색을 정하면 글자는 배경 밝기에 따라 흰색 또는 검정으로 표시됩니다. 완료한 일정에는 마감 알림을 보내지 않습니다.
- **삭제**: `삭제`를 누르면 `일정 삭제` 확인 패널이 뜨고, 그 패널의 `삭제`를 눌러야 지워집니다. 구글 캘린더 연동을 켜 두었고 구글 일정과 연결된 일정이면 확인 문구 아래에 `구글 캘린더에서도 삭제됩니다.` 또는 `구글 캘린더에는 남습니다.`가 함께 표시됩니다. 연동을 꺼 두었을 때는 이 앱이 만든 일정에만 `구글 캘린더 연동을 다시 켜면 구글에서도 삭제됩니다.`가 표시됩니다([삭제 규칙](#일정-동기화-규칙)).
- 자정이 지나거나 Windows 시계·표준 시간대를 바꾸면 D-day와 ‘오늘’이 새 날짜로 바뀌고, 제목을 아직 쓰지 않았고 날짜도 바꾸지 않은 추가 입력줄은 새 오늘 날짜로 옮겨집니다.
- 목록 색상·투명도·글자 크기는 [설정](#설정)에서 바꿉니다.

### 원본 일정 창의 버튼

| 버튼 | 동작 |
| --- | --- |
| 십자 화살표 (`이동/크기 조절`) | 켜면 상단 띠를 끌어 창을 옮기고 크기를 바꿀 수 있습니다. 설정이나 모니터 선택을 열면 자동으로 꺼집니다. |
| 모니터 아이콘 (`모니터 선택`) | 연결된 모니터 중 위젯을 둘 모니터를 고릅니다([모니터별 위치](#모니터별-위치)). |
| 설정 아이콘 (`설정`) | 창 안에 설정 패널을 엽니다. |
| 👤 (`캐릭터 켜기 / 끄기`) | TODO 창 주위에 캐릭터를 켜고 끕니다. 꺼져 있으면 흐리게 표시합니다([미니 창 캐릭터](#캐릭터)). |
| `X` (`일정 목록 닫기`) | 목록만 닫습니다. 달력과 앱은 계속 실행됩니다. |
| `달력` | 달력을 다시 표시하고 앞으로 가져옵니다. 열려 있는 목록도 유지합니다. |
| `연락 · 알림` | 메시지 전송과 마감 알림 설정 창을 엽니다. |
| `음악` | 좌클릭은 음악 창, 우클릭은 재생 설정 메뉴(반복·랜덤·한 곡 반복, 재생·정지·이전/다음 곡, 곡·플레이리스트 선택)입니다. |

`Esc`는 열린 `일정 삭제` 확인·`일정 수정`·모니터 선택·설정 패널을 차례로 닫고, 닫을 것이 없으면 창을 숨깁니다.

### 트레이 아이콘

아이콘을 좌클릭하거나 더블클릭하면 달력이 열리고, 이미 열려 있으면 앞으로 가져옵니다. 일정 목록도 열려 있으면 함께 앞으로 가져옵니다. 우클릭 메뉴는 `열기`, `연락 · 알림`, `음악`, `위치 초기화`, `종료`입니다. 메뉴가 열려 있을 때 아이콘을 다시 우클릭하면 메뉴만 닫힙니다.

- `위치 초기화`는 달력을 주 모니터 작업 영역 중앙으로 옮깁니다. 목록이 열려 있으면 옮긴 달력 옆에 다시 배치합니다.

## 미니 창

달력 창은 투명한 창 안에 달력 보드, 선택적으로 표시하는 음악 막대, 캐릭터를 그리는 메인 화면입니다. 머리띠의 체크리스트 버튼이나 메뉴의 `일정 목록 열기 / 닫기`를 누르면 달력 오른쪽에 목록이 열리고, 오른쪽 공간이 부족하면 왼쪽에 엽니다. 양쪽 공간이 모두 부족하면 작업 영역 안으로 위치를 보정합니다. 같은 버튼을 다시 누르거나 목록의 `X`를 누르면 목록만 닫힙니다. 목록에서 일정을 고치면 달력에도 반영됩니다. 달력을 숨기거나 `Alt+F4`로 닫으면 목록도 숨고, 트레이의 `열기`는 달력을 다시 엽니다.

### 기본 동작

- **이동**: 머리띠를 끌면 창 전체가 움직입니다. 캐릭터·날짜 칸·음악 막대를 끌어도 창은 움직이지 않으며, 캐릭터 자리는 `드래그로 위치 설정`으로 옮깁니다. 머리띠 위의 `‹`·`›`·스타일 드롭다운·`⚙`·TODO 버튼도 끌면 창이 움직이고, 끌지 않고 누르면 그대로 클릭입니다. 이동 직후에는 클릭 메뉴나 말풍선이 열리지 않습니다.
- **크기**: 달력 네 모서리를 끌면 달력 보드 크기가 바뀌고, 끄는 모서리의 반대쪽 모서리는 제자리에 있습니다. 창은 달력 보드와 보드 바깥의 캐릭터를 모두 감싸도록 자동으로 맞춰지며(모서리를 놓은 뒤 다시 맞춤), 보드의 화면 위치·크기는 따로 저장되어 캐릭터를 옮기거나 숨겨도 보드는 제자리를 지킵니다.
- **팝업**: 열린 메뉴·드롭다운·말풍선은 열 때 쓴 버튼이나 같은 대상을 한 번 더 누르면 닫힙니다. 머리띠의 스타일 드롭다운은 창의 다른 곳을 누르거나, 창을 끌어 옮기거나, 다른 앱으로 넘어가면 닫힙니다. 창을 끌어 옮기면 음량 바·메뉴·말풍선·기간 선택도 함께 닫힙니다.
- **`Esc`**: 캐릭터 위치 설정 모드와 열려 있는 팝업(스타일 드롭다운, 날짜 선택, 일정 말풍선, 기간 선택, 재생 목록, 음량 바, 메뉴)을 하나씩 닫고, 닫을 것이 없으면 미니 창을 숨깁니다(앱은 트레이에서 계속 실행). 트레이 아이콘·`열기`·[단축키](#단축키로-맨-앞에-띄우기)로 숨긴 창을 그대로 다시 엽니다.

### 달력

- **머리띠**: 왼쪽부터 `‹`, 스타일(테마) 드롭다운, 기간 표시, `⚙` 설정, TODO 목록 버튼, `›` 순서이며 제본 링 두 개가 표시됩니다. 버튼이 아닌 곳을 누르면 표시 일수 선택이 열립니다.
- **기간**: `며칠씩 보여 줄까요?`에서 1~7일을 고릅니다. 기본은 월요일부터 일요일까지 7일입니다. 1~6일은 오늘(또는 고른 날짜)부터, 7일은 그 날짜가 속한 월요일부터 표시하고, 화살표는 선택한 일수만큼 이동합니다. `오늘로 이동`, `달력`(날짜를 고르면 그 날짜 기준으로 표시)도 있습니다. 자정이 지나 날짜가 바뀌면, 기본 기간(이번 주 또는 오늘부터)을 보고 있던 경우에만 새 날짜에 맞춰 옮겨 가고 화살표나 `달력`으로 옮겨 둔 기간은 그대로 둡니다.
- **페이지 넘김 효과**: `‹`/`›`로 기간을 옮길 때의 움직임은 설정의 `넘김 애니메이션 (미니 창)`에서 고릅니다(효과 1~6은 약 0.5초).
  - `효과 1 · 위로 넘기기`(기본): 벽걸이 달력처럼 날짜 칸 페이지가 머리띠 아래쪽 가장자리를 축으로 위로 젖혀져 머리띠와 달력 위쪽을 넘어가 사라지고(`›`), `‹`는 이전 페이지가 위에서 머리띠 위로 내려와 덮입니다. 머리띠는 그대로 있고 기간 표시만 페이지가 넘어가는 중간에 바뀝니다.
  - `효과 2 · 모서리 넘기기`: 머리띠까지 포함한 종이 전체가 위쪽 제본 링에 매달린 채 오른쪽 아래 모서리부터 대각선으로 말려 넘어가고(`›`), `‹`는 이전 페이지가 왼쪽 위에서부터 내려와 오른쪽 아래 모서리까지 덮입니다. 기간 표시도 종이와 함께 넘어가고 링은 맨 위에 그대로 남습니다.
  - `효과 3 · 위로 넘기기 (뒷면 1/3)`, `효과 4 · 모서리 넘기기 (뒷면 1/3)`: 효과 1·2와 같이 넘어가되, 링(종이 위쪽 가장자리) 위로 넘어간 뒷면은 그 종이 높이의 1/3까지만 보이고 끝부분은 흐려지며 사라지므로 바탕화면을 덜 가립니다.
  - `효과 5 · 위로 넘기기 (링 위 숨김)`, `효과 6 · 모서리 넘기기 (링 위 숨김)`: 효과 1·2와 같이 넘어가되, 링 위로는 뒷면이 전혀 보이지 않아 종이가 링 뒤로 넘어가는 것처럼 보입니다. 효과 3~6에서 `‹`는 그 반대로, 이전 페이지가 흐려진 부분이나 링 선에서 나타나 내려오며, 링은 넘어가는 종이 위에 그대로 그려집니다.
  - `애니메이션 없음`: 넘기는 움직임 없이 바로 바뀝니다. 넘김용 화면을 만들지 않으므로 그 메모리도 쓰지 않습니다. 효과 1~6을 쓸 때는 미니 창이 열린 뒤 한가할 때 넘김용 화면을 미리 만들어 두어(약 8 MB) 첫 넘김도 바로 시작하고, 넘기지 않는 동안에는 빈 채로 화면 밖에 둡니다.
  - 효과 선택은 `저장`할 때 적용되고 다음 클릭부터 바뀝니다. 넘기는 도중에 다시 누르면 진행 중이던 넘김을 바로 끝내고 새로 시작하며, 데이터·일수·테마·자정 갱신 등 다른 이유로 화면이 갱신되거나 창을 숨기거나 옮기거나 크기를 바꾸면 그 즉시 끝납니다. Windows의 애니메이션 효과를 꺼 두었거나 창이 보이지 않을 때는 효과 없이 바로 바뀝니다.
- **테마**: 스타일 드롭다운에서 Light, Dark, Blue, Pink, Modern을 고르면 미니 창·원본 창·보조 창의 테마가 함께 바뀌고 저장됩니다([테마](#테마)).
- **일정 블록**: 제목(긴 제목은 단어 단위로 줄바꿈해 칸이 허용하는 만큼 여러 줄), 지정한 시간(윗줄 왼쪽), 남은 날짜(`D-3`·`D-day`·`D+2`, 윗줄 오른쪽)를 표시합니다. 완료한 일정은 D-day 없이 흐리게 취소선으로 나타나고 그날 목록의 맨 뒤로 갑니다. 설정의 `일정 블록에 D-day 표시 (미니 창)` ON/OFF 스위치(기본 ON)로 D-day를 끌 수 있습니다. 카드 색이 없는 일정은 일정 ID로 정해지는 고정 색을 쓰고, 같은 날에는 가능한 한 서로 다른 색을 배정합니다. 공간을 넘는 일정은 `+ N개 일정`으로 표시합니다.
- **일정 편집**:
  - 날짜를 좌클릭하면 그날의 모든 일정이 말풍선으로 열립니다. 일정마다 `완료`/`미완료`, `수정`, `삭제`(한 번 더 눌러 `정말 삭제`)가 있고, `새 일정`을 누르면 제목·날짜·`시간 지정`을 입력하는 편집기가 펼쳐집니다(`취소`/`저장`). 같은 날짜를 다시 누르면 말풍선이 닫힙니다.
  - `완료`·`삭제`·`저장`의 결과(예: `‘…’ 일정을 삭제했습니다.`)는 편집기를 접은 상태에서도 말풍선 맨 아래에 표시됩니다.
  - 일정 블록을 우클릭하면 그 일정의 `수정`, `완료`/`미완료`, `삭제`(두 번 확인) 말풍선이 열립니다.
  - 구글 캘린더 연동을 켜 두었고 구글 일정과 연결된 일정은 `정말 삭제`를 기다리는 동안 그 아래에 `구글 캘린더에서도 삭제됩니다.`(이 앱이 만든 참석자 없는 일정) 또는 `구글 캘린더에는 남습니다.`가 표시됩니다. 연동을 꺼 두었을 때는 이 앱이 만든 일정에만 `구글 캘린더 연동을 다시 켜면 구글에서도 삭제됩니다.`가 표시됩니다.
- **공휴일**: 양력 공휴일, 설날·부처님오신날·추석, 대체공휴일과 코드에 등록된 선거일·임시공휴일의 이름을 날짜 칸에 표시합니다. 일요일·공휴일은 요일과 날짜가 빨간색 계열, 토요일은 요일이 파란색 계열입니다. 새로 지정되는 임시공휴일은 `ScheduleWidget/Services/KoreanHolidays.cs`에 추가해야 합니다.

### 음악 막대

달력 아래에 같은 폭의 MP3 플레이어형 막대가 표시됩니다. 음악 창과 같은 플레이어·설정을 사용합니다.

| 조작 | 동작 |
| --- | --- |
| 목록 아이콘 (`플레이리스트 설정 열기`) | 음악 창을 열거나 닫습니다. 재생 중이면 창을 닫아도 음악은 계속됩니다. |
| 재생 소스 드롭다운 | 위젯 플레이리스트, 또는 Windows 미디어 세션을 제공하는 다른 앱(브라우저의 YouTube·YouTube Music, Spotify 등)을 고릅니다. 자세한 동작은 아래 `재생 소스` 항목을 봅니다. |
| `⏮` `▶/⏸` `⏭` | 선택한 소스의 이전 곡, 재생/일시정지, 다음 곡을 조작합니다. |
| 스피커 | 마우스를 올리면 세로 음량 바가 나타나고, 누르면 음소거/음소거 해제입니다. 자세한 동작은 아래 `스피커` 항목을 봅니다. |
| `순차` / `랜덤` / `1곡` | 누를 때마다 순차 → 랜덤 → 한 곡 반복 → 순차로 바뀝니다(위젯 플레이리스트의 재생 방식). 재생 소스로 다른 앱을 고른 동안에는 이 버튼이 숨겨집니다. |

- **재생 소스**:
  - 다른 앱을 고르면 위젯 음악은 일시정지되고, 위젯 목록으로 돌아오면 고르던 다른 앱을 일시정지합니다.
  - 고른 앱이 닫혀 목록에서 5초쯤 보이지 않으면 막대는 위젯 플레이리스트로 돌아갑니다(미니 창이 보이는 동안, 위젯에 플레이리스트가 있을 때).
- **스피커**:
  - 위에 마우스를 올리거나 `Tab`으로 초점을 주면 바로 위에 세로 음량 바가 나타나고(맨 위에 퍼센트), 포인터가 스피커와 음량 바를 모두 벗어나면 0.3초쯤 뒤 닫힙니다.
  - 스피커를 누르면 음소거/음소거 해제입니다. 해제하면 음소거 직전 음량으로 돌아가며, 이 값은 저장돼 재시작해도 남고 기록이 없으면 50%입니다.
  - 스피커나 음량 바 위에서 마우스 휠을 굴리거나 초점이 있는 스피커에서 `↑`/`↓`를 누르면 5%씩 바뀝니다.
  - 스피커 클릭·휠·`↑`/`↓`로 바꾼 음량은 조작이 멈춘 뒤 한 번에 저장되고, 음량 바를 끌어 바꾼 값은 바가 닫힐 때 저장됩니다.
  - 재생 소스로 다른 앱을 고른 동안에는 그 앱의 Windows 음량(볼륨 믹서 값)을 보여 주고 바꿉니다. 음소거 해제는 그 앱의 직전 음량으로 돌아가고(기록이 없으면 50%), 위젯에 저장된 음량은 바뀌지 않으며 다른 앱의 음량은 저장하지 않습니다. 볼륨 믹서에서 바꾼 값은 3초 안팎(음량 바가 열려 있으면 1.5초 안팎)에 따라옵니다.
  - 브라우저는 탭별이 아니라 브라우저 전체의 음량이고, 앱이 소리를 한 번 내기 전에는 위젯 음량이 보이며 바꿔도 적용되지 않습니다.
- **제목과 재생 위치 줄**: 곡이 있으면 버튼 줄 아래에 곡 제목 줄과 재생 위치 줄이 항상 함께 표시됩니다(막대는 3줄). 제목은 재생 중이고 미니 창과 음악 막대가 보일 때만 오른쪽에서 왼쪽으로 흐르고, 일시정지하면 앞부분이 왼쪽 끝에 보이도록 멈췄다가 다시 재생하면 이어서 흐릅니다. 재생 위치 줄도 재생 중이고 창이 보일 때만 0.5초마다 갱신되며(일시정지·이동 때는 한 번 갱신), 마우스를 올려도 막대 높이와 달력은 그대로입니다.
- **제목 클릭**: 위젯 곡이면 `지금 재생 목록`이 열립니다(곡을 누르면 재생, `▲`/`▼`로 순서 변경). 다른 앱이 소스이면 그 곡이 재생 중인 탭이나 창을 맨 앞으로 가져옵니다. 브라우저(Edge·Chrome·Whale·Brave·Firefox 등)는 Windows UI 자동화로 탭 줄에서 곡 제목이 든 탭을 찾아 선택하므로 확장 프로그램이 필요 없고, 맞는 탭이 없으면 그 앱의 창만 앞으로 가져옵니다. 탭 찾기는 백그라운드에서 하며 찾는 동안 다시 누른 클릭은 무시합니다. 제목은 `Tab`으로 초점을 줄 수 있고 `Enter`나 `Space`를 누르면 클릭과 같습니다. `지금 재생 목록`은 재생 중인 곡이 보이는 위치로 열리고, 스크롤해 둔 위치는 곡이 바뀌거나 순서를 바꿔도 유지됩니다.
- **재생 위치 줄**: `현재 시간 ━━●━━ 전체 길이`를 보여 주며 클릭·드래그 또는 휠(5초)로 이동합니다. 다른 앱은 해당 미디어 세션이 길이와 위치 이동을 지원할 때만 쓸 수 있습니다.
- **다른 앱 정보**: 미니 창이 보이는 동안 5초마다 확인하고, 다른 앱을 재생 소스로 고른 동안과 재생 소스 드롭다운이 열려 있는 동안에는 1.5초마다(드롭다운을 열면 바로 한 번) 확인합니다. 숨긴 동안은 멈췄다가 다시 열면 바로 확인합니다. 일시적으로 읽지 못하면 직전 결과를 5초 정도 유지해 막대가 깜빡이지 않습니다. 위젯의 숨은 YouTube 플레이어는 목록에서 제외합니다. Windows가 미디어 세션을 제공하지 않으면 다른 앱 목록은 비어 있습니다.
- 달력 우클릭 메뉴의 `달력 아래 음악 막대 표시`로 막대를 숨기거나 다시 표시할 수 있습니다.

### 캐릭터

- **여러 캐릭터**: 최대 3마리를 표시합니다. 캐릭터마다 동작·크기(50~300%)·`보이기`를 따로 저장하며 100%는 달력 높이의 절반입니다. 음악 막대에 제목·재생 위치 줄이 생기거나 사라져도 캐릭터 크기는 변하지 않습니다.
- **클릭**: 캐릭터를 좌클릭하면 `캐릭터 선택`, 우클릭하면 `캐릭터 설정`이 열립니다(같은 캐릭터를 다시 우클릭하면 닫힘). 캐릭터를 끌어도 창은 움직이지 않습니다(창은 머리띠를 끌어 옮기고, 캐릭터 자리는 `드래그로 위치 설정`으로 옮깁니다). 캐릭터 화면 자체는 마우스를 받지 않고 캐릭터 몸통 위의 투명 히트 박스만 입력을 받으므로, 캐릭터가 없는 곳의 달력·음악 막대는 그대로 클릭할 수 있습니다.
- **`캐릭터 설정`**: 제목이 `캐릭터 설정 - Dewey`처럼 그 캐릭터 이름으로 표시됩니다. 캐릭터 목록(캐릭터마다 `보이기`, `바꾸기`, `빼기`, `캐릭터 추가 (최대 3)`), 선택한 캐릭터의 동작과 크기, `미니 창에 캐릭터 표시`, 위치(달력 왼쪽/오른쪽·세로 위치·달력과 간격), `드래그로 위치 설정`, 두 번 눌러 확인하는 `초기화`(모든 캐릭터 보이기·크기 100%·기본 배치·동작 대기, 캐릭터 목록은 유지)가 있습니다. 값은 즉시 반영·저장되며 창을 여는 것만으로는 바뀌지 않습니다. 다른 캐릭터를 우클릭하면 그 캐릭터로 전환됩니다. `보이기`를 끈 캐릭터는 목록에 남은 채 화면·배치·클릭에서 빠집니다. 이 창은 캐릭터가 있는 모니터의 작업 영역 안에 열리고 `Esc`로도 닫힙니다.
- **`캐릭터 선택`**: 캐릭터 미리보기·가져오기·내보내기·삭제·적용 창입니다([사용자 캐릭터](#사용자-캐릭터)). 미니 창에서 연 경우 `드래그로 위치 설정` 버튼이 함께 나오며, 누르면 캐릭터는 바꾸지 않고 배치 모드로 들어갑니다. `Esc`를 누르면 창이 닫힙니다(삭제 확인 중이면 확인만 취소).
- **드래그로 위치 설정**: 이 모드에서만 각 캐릭터를 달력의 위·아래·왼쪽·오른쪽 또는 달력과 겹치는 위치로 끌 수 있습니다. 배너에 `처음 배치로`(기본 배치로 복귀)와 `완료`가 있으며 `Esc`나 우클릭으로도 끝냅니다. 모드 동안에는 창이 캐릭터 주위로 넉넉히 커진 채 유지되어 끄는 중에 흔들리지 않고, 끝내면 캐릭터에 맞게 다시 줄어듭니다. 달력 보드(달력과 음악 막대) 위에 놓으면 보드 폭·높이에 대한 백분율로, 보드 바깥에 놓으면 가까운 가장자리에서의 거리(px)로 저장되어 달력 크기를 바꿔도 위치 관계가 유지됩니다.
- **기본 배치**: 캐릭터는 달력 옆(`달력 왼쪽`/`달력 오른쪽`)에 나란히 서며 `세로 위치`(위 0%~아래 100%)와 `달력과 간격`(-80~60px, 음수는 달력 위로 겹침)으로 조절합니다. 왼쪽/오른쪽이나 간격을 바꾸면 끌어 둔 위치를 지우고 기본 배치로 돌아가고, `세로 위치`만 바꾸면 저장된 좌우 위치는 유지하고 높이만 기본값에 맞춥니다.
- **캐릭터별 마지막 자리 기억**: 캐릭터를 바꾸거나(`바꾸기`·`캐릭터 추가`·`빼기`, 삭제로 기본 캐릭터 흰 모찌로 돌아가는 경우 포함) 다시 넣으면 그 캐릭터가 마지막에 서 있던 자리로 돌아갑니다. 같은 캐릭터를 두 마리 세우면 각각 따로 기억하고, 한 번도 놓아 본 적 없는 캐릭터는 기본 배치에서 시작합니다. `초기화`·`처음 배치로`·왼쪽/오른쪽이나 간격 변경은 지금 목록에 올라 있는 캐릭터의 기억만 지우고 다른 캐릭터의 기억은 남깁니다.
- **TODO 창 옆 캐릭터(👤)**: 원본 창의 👤 버튼으로 TODO 창 주위에도 캐릭터를 켜고 끕니다(기본 꺼짐, 설정 저장).
  - TODO 창이 보일 때만 나타나며 미니 창과 같은 캐릭터·동작·크기·보이기 설정을 씁니다. 위치(왼쪽/오른쪽·세로 위치·간격, 드래그로 옮긴 자리, 캐릭터별 마지막 자리)는 미니 창과 따로 저장해 달력 대신 TODO 창을 기준으로 자리 잡습니다(처음에는 기본 배치).
  - 좌클릭 `캐릭터 선택`, 우클릭 `캐릭터 설정`, `드래그로 위치 설정`도 같습니다. 음악 막대는 없지만 `음악 반복` 동작은 음악 재생에 맞춰 움직입니다.
  - TODO 창을 옮기거나 크기를 바꾸면 따라가며, 캐릭터가 없는 곳을 누르면 TODO 창이 클릭됩니다. 여기서 캐릭터를 끌어도 TODO 창은 움직이지 않고 미니 창의 달력 위치도 건드리지 않습니다.
  - 여기서 연 `캐릭터 설정`은 `TODO 창 옆에 캐릭터 표시`(끄면 👤도 꺼집니다)·`위치 (TODO 창 기준)`으로 표시됩니다. `초기화`는 캐릭터별 보이기·크기·동작(미니 창과 같은 값)을 되돌리고 위치는 TODO 창 옆 배치만 기본값(TODO 창 왼쪽·아래·간격 8px)으로 돌리며, `미니 창에 캐릭터 표시`와 미니 창의 배치는 바꾸지 않습니다.
- **동작**: 캐릭터별로 `대기`·`인사`·`점프`·`활동`·`왼쪽 걷기`·`오른쪽 걷기`·`기다리기`·`집중`·`당황`과 `랜덤 순회`를 저장합니다. `pet.json`에 음악 동작을 선언한 캐릭터에는 그 동작(`음악 듣기`·`신남`·`싫어함`·`심취`)과, 음악이 재생되는 동안 음악 동작을 순회하고 멈추면 대기로 돌아가는 `음악 반복`이 추가됩니다. `키보드 1`·`키보드 2`(`keyboard1`·`keyboard2`)를 선언한 캐릭터에는 그 동작도 버튼으로 생기며, 이 둘은 음악 동작이 아니어서 `음악 반복`에는 쓰이지 않습니다. 스프라이트 캐릭터에는 `타이핑 반응`도 있습니다: 어느 창에서든 키를 누를 때마다 캐릭터가 타자 동작을 한 장면씩 넘기고(봉고 캣처럼 키마다 장면이 바뀜), 약 0.9초 동안 키가 없으면 대기로 돌아갑니다. 타자 동작은 `키보드 1`·`키보드 2`를 입력 묶음마다 번갈아 쓰고(하나만 있으면 그것), 없으면 `당황`·`점프`를 번갈아 씁니다. 어떤 키를 눌렀는지는 읽지 않고 눌렀다는 사실만 세며(Raw Input, 키보드 후킹 없음), 기록·저장·전송하지 않습니다. 이 동작의 캐릭터가 화면에 보일 때만 키 입력을 받고, 관리자 권한으로 실행한 앱에서 친 키는 Windows가 넘겨주지 않아 반응하지 않습니다. Windows의 애니메이션 효과를 끄면 캐릭터는 지금 동작의 한 장면에서 멈추고, 다시 켜면 곧바로 움직입니다.

### 달력 우클릭 메뉴

달력의 빈 곳을 우클릭하면 마우스 포인터 위치에 메뉴가 열립니다. 키보드의 메뉴 키나 `Shift+F10`으로도 열 수 있으며 이때는 캐릭터 위(캐릭터를 숨겼다면 달력 아래)에 열립니다. 캐릭터를 모두 숨겨도 이 메뉴로 다시 켤 수 있습니다.

- `달력 아래 음악 막대 표시`, `캐릭터 표시`, `캐릭터 크기`(첫 번째 캐릭터의 크기, 캐릭터가 여러 마리면 `1번째 캐릭터 크기`)
- `일정 목록 열기 / 닫기`, `캐릭터 설정`, `캐릭터 추가`(3마리면 비활성), `1번째 캐릭터 빼기`(한 마리뿐이면 `이 캐릭터 빼기`가 비활성). 두 번째·세 번째 캐릭터를 빼려면 `캐릭터 설정`의 `빼기`를 씁니다.
- `음악`(좌클릭 음악 창, 우클릭 반복·랜덤·곡 선택 메뉴), `연락 · 알림`, `⚙ 설정`, `종료`

### 캐릭터 화면 자동 복구

캐릭터는 WebView2 화면 안에서만 그려지므로, 그 화면이 멈추거나 사라지면 달력은 남고 캐릭터만 없어질 수 있습니다. 다음 상황에서 복구를 시도합니다.

- **프로세스 오류**: 화면의 렌더러·GPU 프로세스가 끝나거나 응답이 없으면 약 1초 뒤 화면을 다시 불러오고, 브라우저 프로세스가 끝나면 캐릭터 화면을 새로 만듭니다. 최근 1분 안에 이미 3번 복구했다면 다음 시도는 1분 뒤로 늦춥니다.
- **화면 시작 실패**: 캐릭터 화면(WebView2)이 시작되지 못하면 `캐릭터를 표시하려면 WebView2 설치를 확인해 주세요.`를 표시한 뒤 새 화면으로 다시 시도합니다(횟수 제한은 위와 같습니다).
- **화면·DPI 변경, 절전 복귀, 잠금 해제·원격 연결, 창 다시 표시**: 1초 뒤 캐릭터 화면이 응답하는지 확인합니다. 응답이 없으면 다시 불러오고, 응답하면 배치를 다시 보내 캐릭터를 다시 그리게 한 뒤 잠시 뒤 실제 창에 캐릭터가 그려졌는지 확인해, 비어 있으면 다시 그리고 그래도 비어 있으면 캐릭터 화면을 새로 만듭니다. 이미지를 그리지 못한 캐릭터가 있어도 나머지 캐릭터는 같은 방식으로 확인합니다.
- **2분마다 조용한 확인**: Windows 이벤트 없이 화면이 멈추는 경우를 위해, 창이 보이는 동안 2분마다 캐릭터 화면이 응답하는지와 실제 창에 캐릭터가 그려졌는지 확인합니다. 정상이면 다시 그리지도 기록하지도 않고, 응답이 없으면 다시 불러오며, 비어 있으면 위와 같이 다시 그리고 한 번 더 본 뒤 그래도 비어 있으면 새로 만듭니다. 창을 숨긴 동안, 캐릭터 위치 설정 중, 넘김 애니메이션 중, 다른 확인이 진행 중일 때는 건너뜁니다.
- **픽셀 확인의 한계**: 캐릭터가 달력 위에 거의 다 겹쳐 있으면(바깥으로 나온 부분이 4분의 1 미만) 픽셀로는 캐릭터와 달력을 구분할 수 없어 응답 확인만 합니다. 기본 배치(달력 옆)에서는 픽셀까지 확인합니다.
- **캐릭터 파일을 읽지 못할 때**: 동기화나 백신이 파일을 잡고 있는 등의 이유로 캐릭터 파일을 잠시 읽지 못하면, 그 캐릭터는 목록과 자리를 그대로 둔 채 그 자리에 `캐릭터 파일을 읽지 못했습니다. 클릭해서 캐릭터를 다시 선택해 주세요.`를 표시하고 3초쯤 뒤 한 번 다시 읽습니다. 파일이 망가진 두 번째·세 번째 캐릭터만 목록에서 빠지며, 그 캐릭터의 드래그 위치도 함께 빠져 뒤의 캐릭터는 제자리를 지킵니다. 첫 번째 캐릭터는 목록에서 빠지지 않고 같은 안내가 남습니다.
- **기록**: `%LocalAppData%\ScheduleWidget\pet-log.txt`에 복구 시도, 절전 복귀, 화면 확인 결과가 한 줄씩 남습니다. 64KB를 넘으면 이전 내용은 `pet-log.old.txt`로 바뀝니다.

### 성능 처리

- 날짜 칸은 다시 만들지 않고 기존 항목의 내용만 갱신하며, 일정 블록도 내용이 바뀐 날짜만 다시 구성합니다.
- 메뉴·말풍선·기간 선택·날짜 선택 팝업은 미니 창이 열린 뒤 유휴 시간에 미리 측정합니다.
- 평소 캐릭터 WebView는 캐릭터들을 감싸는 영역만 차지합니다. 드래그 위치 설정 중에는 화면이 움직이지 않도록 창 전체를 사용합니다.
- 연속으로 발생하는 위치·크기 저장은 300ms 동안 모아 한 번 처리합니다.
- YouTube 재생 위치와 길이는 값이 바뀔 때만 전달하므로 일시정지 중 같은 시간을 반복해서 보고하지 않습니다.
- 흐르는 제목은 재생 중이고 보일 때만 초당 30번 움직이며, 멈추거나 숨기면 애니메이션을 아예 없애 곡이 올라가 있어도 쉬는 동안에는 화면을 다시 그리지 않습니다.

## 사용자 캐릭터

캐릭터는 `캐릭터 선택` 창에서 고릅니다. 미니 창의 캐릭터를 좌클릭하거나, `캐릭터 설정`의 `바꾸기`·`캐릭터 추가`, 달력 우클릭 메뉴의 `캐릭터 추가`, 설정의 `캐릭터 선택 / 가져오기`로 엽니다. 고른 뒤 `이 캐릭터 적용`을 눌러야 바뀝니다.

- **기본 캐릭터**: 흰 모찌·검은 모찌·파란 모찌·빨간 모찌가 앱 폴더의 `DefaultPets\<id>`(`pet.json` + `spritesheet.webp`, 15행 v4 시트에 음악 동작과 키보드 1·2)로 함께 설치되어 캐릭터 선택 창의 맨 앞 `기본 캐릭터` 그룹에 보입니다. 처음 실행(저장된 캐릭터 없음)의 캐릭터는 흰 모찌입니다. 고른 캐릭터를 지금 쓸 수 없으면(삭제됨, Codex 미설치, 파일을 읽을 수 없음) 그 자리에 흰 모찌를 보여 주되 저장된 선택은 바꾸지 않아, 그 캐릭터가 다시 생기면 그대로 돌아옵니다. 기본 캐릭터는 삭제할 수 없고 내보낼 수 있으며, 구글 드라이브에는 올리지 않습니다. 기본 캐릭터와 시트가 똑같은 파일은 캐릭터 가져오기에서 "같은 캐릭터가 이미 있습니다"로 추가하지 않고(그 기본 캐릭터를 선택), 드라이브에서도 받지 않습니다.
- **Codex 캐릭터**: 앱에는 Codex 캐릭터가 들어 있지 않습니다. 이 PC에 OpenAI Codex(데스크톱 앱)가 설치되어 있으면 시작할 때 Codex의 `app.asar`에서 Codex, Dewey, Fireball, Hoots, Rocky, Seedy, Stacky, BSOD, Null Signal 스프라이트를 `%LocalAppData%\ScheduleWidget\CodexPets\builtin`으로 복사해 `Codex` 그룹에 보여 줍니다. Codex 버전이 바뀌면 다시 복사하고, Codex를 지우면 복사본도 지웁니다. 삭제·내보내기·드라이브 보관은 되지 않습니다. 사용자가 Codex에서 만든 펫(`%USERPROFILE%\.codex\pets`)은 `내 Codex 펫` 그룹에 함께 보입니다(내보내기 가능). Codex가 없으면 Codex 캐릭터를 고른 캐릭터 자리에 흰 모찌가 보이고(선택은 그대로 저장되어 Codex를 설치하면 다시 보임), 캐릭터 선택 창에 안내가 표시됩니다. 이전 버전이 앱 폴더에 두던 `Characters` 폴더는 시작할 때 지웁니다.
- **가져오기**: `캐릭터 가져오기`로 PNG·WebP·GIF·JPG/JPEG·BMP 이미지, Codex `pet.json`, 이 앱에서 내보낸 `.zip`을 고릅니다. 가져와도 바로 적용되지는 않고 목록에 추가됩니다. 일반 이미지와 GIF는 스프라이트 동작 없이 원본 모습으로 표시됩니다.
- **저장 위치**: 가져온 캐릭터는 이 PC의 사용자 데이터 폴더 `%LocalAppData%\ScheduleWidget\Pet\<캐릭터 ID>`에 이미지와 새 `pet.json`으로 복사됩니다. 앱 폴더를 옮기거나 새 버전으로 바꿔도 그대로 남으며, 목록은 기본 캐릭터·Codex 캐릭터(위)와 이 폴더만 읽습니다.
- **규격**:
  - `pet.json`은 64KB 이하이고 이미지 경로가 `pet.json` 폴더 안의 상대 경로여야 합니다. 이미지는 25MB·2,500만 픽셀 이하이며, 스프라이트시트는 1536×1872(v1, 9행)·1536×2288(v2, 11행)·1536×2704(v3, 13행)·1536×3120(v4, 15행)·1536×3536(v5, 17행) 중 하나여야 합니다. v4·v5는 이 앱의 확장 형식으로, 휴대폰 앱은 아직 가져오지 못합니다.
  - 가져올 때(`캐릭터 가져오기`, `.zip`, 예전 `Pet` 폴더 이관, 드라이브에서 받기) 이미지 파일 머리말로 크기를 검사해 맞지 않으면 이유를 알리고 거부합니다.
  - 이미 저장된 캐릭터의 이미지를 그리지 못하면(한 번 다시 시도한 뒤) 그 캐릭터 자리에 `이름: 이미지 크기가 캐릭터 형식과 맞지 않습니다.` 또는 `이미지를 읽지 못했습니다.`와 다시 고르라는 안내를 표시합니다.
  - 캐릭터를 바꾼 뒤 이전 이미지가 캐시에서 다시 나오지 않도록 이미지 주소에는 파일 경로·수정 시각·크기로 만든 버전을 붙입니다.
- **삭제**: `캐릭터 삭제`는 위 폴더 바로 아래의 가져온 캐릭터만 확인 후 지웁니다. 사용 중인 캐릭터를 삭제하면 기본 캐릭터 흰 모찌로 바뀌고, 외부 원본 파일은 삭제하지 않습니다. 함께 띄운 다른 캐릭터가 쓰는 캐릭터를 삭제하면 확인 화면에 그 캐릭터도 흰 모찌로 바뀐다고 알려 주고, 창을 취소로 닫아도 캐릭터가 바로 다시 표시됩니다. 삭제한 캐릭터의 기억된 자리도 함께 지웁니다.
- **내보내기**: `캐릭터 내보내기`는 선택한 캐릭터(설치된 Codex에서 가져온 Codex 캐릭터 제외)를 `pet.json`과 이미지가 든 `.zip` 하나로 저장합니다. 다른 PC에서 `캐릭터 가져오기`로 이 파일을 고르면 이름·스프라이트 형식·음악 동작까지 같은 캐릭터로 들어옵니다. `.zip`은 30MB 이하여야 하며, 가져올 때는 `pet.json`과 그 이미지만 꺼내고 이미지가 파일 밖을 가리키거나 `pet.json`이 없으면 거부합니다.

### 예전 `Pet` 폴더 이관

예전 버전은 실행 파일 옆 `Pet` 폴더에 캐릭터를 두었습니다. 앱을 시작할 때와 `캐릭터 선택`을 열 때 그 폴더의 캐릭터를 위 사용자 데이터 폴더로 옮깁니다.

- **대상**: `pet.json`이 든 하위 폴더, `Pet` 바로 아래의 `pet.json`, `Pet` 바로 아래의 그림 파일(PNG·WebP·GIF·JPG·BMP)을 각각 하나의 캐릭터로 복사합니다. 가져오기와 같은 검사를 거칩니다.
- **원본 정리**: 복사본이 다시 읽히는 것을 확인한 뒤에만 원본을 지우고, 비게 된 `Pet` 폴더도 지웁니다. 읽을 수 없거나 규격에 맞지 않는 캐릭터와 관련 없는 파일은 그대로 두며, 그러면 `Pet` 폴더도 남습니다. 옮기지 못한 캐릭터가 있으면 `캐릭터 선택` 아래 안내에 한 번 알려 줍니다(실패한 개수가 바뀔 때만 다시 나옵니다).
- **ID**: 폴더 이름이 안전한 ID(영문·숫자·`-`·`_`, 64자 이하)이면 그대로 쓰고, 아니면 새 ID를 붙이되 `Pet\.migrated`에 옛 이름을 적어 두어 저장돼 있던 캐릭터 선택이 계속 이어집니다.
- **링크와 이름 충돌**: `Pet` 폴더나 그 안의 항목이 링크(정션·심볼릭 링크)면 복사만 하고 링크 너머의 파일은 지우지 않습니다. 같은 폴더 이름의 다른 캐릭터가 이미 있으면 새 ID로 가져오고, 똑같은 캐릭터면 다시 복사하지 않습니다.
- **읽기 전용 앱 폴더**: 원본을 지우지 못해도 복사만 하고 `.migrated`에 기록합니다. 나중에 지운 캐릭터가 옛 폴더에서 되살아나지 않으며, 그때는 옛 폴더도 지우지 않습니다.
- **드라이브 백업**: `캐릭터도 구글 드라이브에 보관`이 켜져 있으면 옮겨 온 캐릭터를 곧바로 올립니다.

### `pet.json` 예시

음악 동작을 추가하는 예시입니다.

```json
{
  "displayName": "내 캐릭터",
  "spritesheetPath": "spritesheet.webp",
  "spriteVersionNumber": 3,
  "animations": {
    "listening": { "row": 9, "frames": 6, "duration": 150 },
    "grooving": { "row": 10, "frames": 4, "duration": 140 },
    "disliking": { "row": 11, "frames": 8, "duration": 140 },
    "immersed": { "row": 12, "frames": 6, "duration": 150 }
  }
}
```

- 스프라이트시트는 `spritesheetPath`와 `spriteVersionNumber`(1~5, 기본 1)로, 단일 이미지는 `imagePath`로 지정합니다. `displayName`이 없으면 폴더 이름을 씁니다.
- 지원하는 음악 동작 키는 `listening`(음악 듣기), `grooving`(신남), `disliking`(싫어함), `immersed`(심취)이고, 타자 동작 키는 `keyboard1`(키보드 1), `keyboard2`(키보드 2)입니다. `row`는 0부터 시작하며 실제 행 범위 안이어야 합니다. `frames`는 1~8(기본 6), `duration`은 프레임당 40~2000ms(기본 150)로 보정됩니다.

## 음악 창 (플레이리스트)

`음악` 버튼·트레이 메뉴의 `음악`·음악 막대의 목록 아이콘으로 여는 `내 플레이리스트` 창입니다.

- 여러 플레이리스트를 만들고(`새 목록`) 이름을 바꿀 수 있으며(`이름 변경`), 음악 파일과 YouTube 영상·Shorts·재생목록 링크를 같은 목록에 섞을 수 있습니다. `삭제`나 곡 삭제(`✕`, `곡 삭제`)는 목록에서만 지우고 원본 파일은 지우지 않습니다.
- 곡을 끌어 원하는 위치에 놓거나 `위로`/`아래로`(또는 곡 오른쪽의 화살표 버튼)로 옮깁니다. 목록 끝에서 끌면 자동 스크롤합니다. 곡을 더블클릭하면 재생합니다.
- `음악 파일 추가`로 고르거나 음악 파일·폴더를 창에 끌어 추가할 수 있습니다. 폴더는 하위 폴더까지 MP3·WAV·WMA·M4A·AAC·FLAC·OGG·AIFF/AIF를 이름순으로 찾습니다. 실제 재생 가능 형식은 Windows에 설치된 코덱에 따릅니다.
- YouTube 링크는 여러 개를 한 줄에 하나씩 넣고 `링크 추가`를 누릅니다. 공개 페이지에서 제목을 가져오며, `재생목록 링크는 안에 있는 곡을 모두 따로 추가`(기본 켬)를 켜 두면 재생목록의 각 영상을 이어서 읽어 개별 곡으로 추가하고, 읽지 못하면 링크 하나로 남기며 이유를 표시합니다. 자동 생성 믹스(`RD…`)는 곡별로 가져올 수 없습니다.
- 재생·일시정지·이전·다음·정지, 음량, 반복(전체 목록)·랜덤·한 곡 반복을 지원합니다. 랜덤은 한 차례의 순서 안에서 같은 곡을 중복 선택하지 않습니다. `초기화`(두 번 확인)는 반복·랜덤·한 곡 반복을 끄고 음량 50%, 재생목록 링크 펼치기 켬으로 되돌리며 플레이리스트와 곡은 그대로 둡니다.
- 곡이 끝나 자동으로 다음 곡으로 넘어갈 때 재생할 수 없는 곡(파일을 찾을 수 없음, 재생 오류, 막히거나 지워진 YouTube 영상, 인터넷 끊김)은 한 번씩 건너뛰고 상태 줄에 `(재생할 수 없는 곡 N개를 건너뛰었습니다)`를 덧붙입니다(한 곡 반복 중이어도 건너뜁니다). 목록을 한 바퀴 돌아도 재생할 곡이 없으면 `재생할 수 있는 곡이 없어 멈췄습니다`라고 알리고 멈춥니다. 곡을 직접 골라 재생하다 실패하면 건너뛰지 않고 멈춰 이유를 표시합니다.
- YouTube는 공식 임베디드 플레이어를 사용합니다. 임베드 재생을 거부하는 영상은 곡을 직접 골라 재생했을 때 기본 브라우저에서 엽니다(`YouTube에서 열기`로 직접 열 수도 있으며, 영상·재생목록 ID로 다시 만든 주소만 열기 때문에 `t=` 같은 추가 값은 버려집니다). 곡이 끝나 자동으로 넘어갈 때는 열지 않고 건너뜁니다. 자동 재생이 막히면 플레이어 안의 재생 버튼을 눌러야 합니다.
- YouTube 플레이어가 멈추거나 종료되면 같은 곡을 같은 위치·일시정지 상태로 다시 열어 이어서 재생하고(1분에 3번까지, 넘으면 멈추고 안내), 인터넷이 없으면 안내 문구를 표시하며 다음 재생 때 다시 시도합니다.
- 인터넷이 끊겨 YouTube 플레이어를 불러오지 못한 곡을 자동으로 건너뛴 뒤에는 다음 YouTube 곡에서 플레이어를 새로 불러오므로, 연결이 돌아오면 자동 진행 중에도 다시 재생됩니다.
- 오른쪽 위 `X`를 눌러도 곡이 재생 중이거나 일시정지 중이면 창만 화면 밖으로 숨기고 곡을 유지하며, 다시 열려면 음악 막대의 목록 아이콘, 원본 창의 `음악` 버튼, 달력 우클릭 메뉴와 트레이 메뉴의 `음악`을 누릅니다. 앱을 종료하면 멈춥니다.
- 곡 목록은 최대 360px 높이 안에서 스크롤되고(끝에서 휠을 굴리면 창이 스크롤), 창은 최소 높이 480px이며 화면이 작으면 작업 영역에 맞춰집니다. 음악 창 슬라이더로 바꾼 음량은 멈춘 뒤 0.6초쯤에 저장됩니다.

플레이리스트와 선택 상태는 일정 데이터와 함께 저장됩니다.

## 연락과 마감 알림

`연락 · 알림`에서 `텔레그램`·`카카오톡`·`휴대폰` 탭에 연동 정보를 넣고 `설정 저장`을 누른 뒤, `메시지 작성`에서 보낼 서비스를 골라 `보내기`를 누릅니다. 일정 카드의 `이 일정 보내기`를 쓰면 일정 내용이 메시지 입력란에 들어갑니다.

| 서비스 | 설정과 동작 |
| --- | --- |
| 텔레그램 | 봇 토큰과 받는 대화 Chat ID(개인 대화의 숫자 ID, 그룹 ID 또는 채널 `@이름`)가 필요하며, 받을 사람이 먼저 봇에 `/start`를 보내야 합니다. `설정 안내 열기`가 안내 문서를 엽니다. |
| 카카오톡 · 나에게 | `talk_message` 동의를 받은 액세스 토큰과 카카오 개발자 앱에 등록해 둔 HTTPS 웹 링크(`등록한 웹 링크 (HTTPS)` 칸)가 필요합니다. `카카오 설정 안내 열기`가 안내 문서를 엽니다. |
| 카카오톡 · 친구에게 | 위 설정에 `친구 UUID`와 친구 메시지 권한이 더 필요하며 전화번호나 이름만으로는 보낼 수 없습니다. |
| 휴대폰 문자·통화 | `휴대폰` 탭에 전화번호를 넣고 `휴대폰 연결 열기`(Windows ‘휴대폰과 연결’)나 `전화 앱 열기`(`tel:` 기본 앱)를 누릅니다. 문자는 서비스에서 `휴대폰 문자 · 복사 후 열기`를 고르면 버튼이 `문자 준비`로 바뀌며, 내용을 클립보드에 복사하고 ‘휴대폰과 연결’을 엽니다. 전송은 그 앱에서 직접 확인해야 합니다. |

카카오톡 메시지는 최대 200자, 텔레그램 메시지는 최대 4096자입니다. `토큰 자동 갱신 설정 (선택)`에 카카오 REST API 키와 리프레시 토큰(Client Secret을 활성화했다면 함께)을 넣으면 액세스 토큰이 만료됐을 때 갱신을 시도합니다. 봇 토큰과 카카오 토큰·리프레시 토큰·Client Secret은 현재 Windows 사용자 범위의 DPAPI로 암호화해 저장하므로 다른 Windows 계정에서는 읽을 수 없습니다(그때는 다시 입력).

`마감 알림` 탭에서 `마감 알림 사용`을 켜고 알릴 시점(0 = 당일, 최대 30일 전)과 시각, 받을 곳(`이 PC에 알림 표시`, `설정한 텔레그램 대화로 보내기`, `카카오톡 나와의 채팅으로 보내기`)을 고릅니다. 시간을 지정한 일정은 그 시각에, 날짜만 있는 일정은 위에서 정한 시각(기본 09:00)에 알립니다.

- 앱 실행 중 30초마다 확인하며 완료한 일정은 제외합니다. 종료·절전 중에는 보낼 수 없습니다.
- 놓친 알림도 마감일이 지나지 않았다면 다음 실행이나 절전 해제 뒤 처리합니다.
- 성공 기록을 서비스별로 저장해 같은 조건의 알림을 반복하지 않습니다. 실패한 알림은 5분 뒤 다시 시도합니다.
- 전송에 실패하면 같은 일정·서비스에 대해 트레이 알림 `마감 알림 전송 실패`가 한 번 뜨고, 그 서비스가 다시 성공할 때까지 `연락 · 알림` 버튼에 마우스를 올리면 마지막 오류가 보입니다.
- 카카오 알림은 나와의 채팅, 텔레그램 알림은 설정한 Chat ID로 보냅니다. SMS 자동 발송은 제공하지 않습니다.
- `알림 설정 초기화`(두 번 확인, `설정 저장`으로 적용)는 알림 끔·당일 09:00·PC로만 되돌리며, 토큰·Chat ID 같은 연동 정보는 지우지 않습니다.

## 설정

원본 창의 `설정` 아이콘을 누르면 창 안에 설정 패널이 열립니다. 미니 창에서는 머리띠의 `⚙`나 우클릭 메뉴의 `⚙ 설정`이 같은 패널을 별도 `설정` 창으로 열며 미니 창은 그대로 남습니다.

| 항목 | 설명 |
| --- | --- |
| `캐릭터 선택 / 가져오기` | 첫 번째 캐릭터를 고르는 `캐릭터 선택` 창을 엽니다. 미니 창이 열려 있으면 `드래그로 위치 설정`도 나옵니다. |
| `미니 창 캐릭터 크기` | 50~300%. 슬라이더를 움직이면 모든 캐릭터가 같은 크기가 됩니다(캐릭터별로 따로 정한 크기는 덮어씀). |
| `캐릭터 위치 (달력 기준)` | `달력 왼쪽`/`달력 오른쪽`, `세로 위치`, `달력과 간격`으로 기본 배치를 정합니다. |
| `모든 창 위에 표시 (일정 창·미니 창)` | 두 창을 항상 위에 고정합니다. |
| `일정 블록에 D-day 표시 (미니 창)` | 미니 달력의 일정 블록에 `D-3`·`D-day`·`D+2`를 표시하는 ON/OFF 스위치입니다(기본 ON). |
| `넘김 애니메이션 (미니 창)` | 미니 달력 `‹`/`›`의 페이지 넘김 모양을 `효과 1 · 위로 넘기기`(기본), `효과 2 · 모서리 넘기기`, `효과 3 · 위로 넘기기 (뒷면 1/3)`, `효과 4 · 모서리 넘기기 (뒷면 1/3)`, `효과 5 · 위로 넘기기 (링 위 숨김)`, `효과 6 · 모서리 넘기기 (링 위 숨김)`, `애니메이션 없음` 중에서 고릅니다. `저장`해야 적용되고 `초기화`는 효과 1로 돌립니다([페이지 넘김 효과](#달력)). |
| `단축키로 맨 앞에 띄우기` | 전역 단축키를 켜고 끄고 바꿉니다([아래](#단축키로-맨-앞에-띄우기)). |
| `미니 창에 캐릭터 표시` | 끄면 달력만 표시합니다. |
| `목록 배경`·`카드 배경`·`제목 글자`·`오늘 D-day`·`예정 D-day`·`지난 D-day` | Windows 색 선택 창으로 원본 일정 창의 색을 바꿉니다. 개별 카드 색은 카드 우클릭 메뉴에서 정합니다. |
| `투명도` | 원본 일정 창의 투명도(30~100%). |
| `테마` | Light, Dark, Blue, Pink, Modern. |
| `폰트 크기` | 원본 일정 창 카드의 `제목`과 `D-Day` 글자 크기(10~24). |
| `Windows 시작` | 로그인할 때 위젯을 자동으로 실행합니다([자동 시작](#자동-시작)). |
| `구글 연동` | 구글 로그인과 두 ON/OFF 스위치입니다([구글 연동](#구글-연동-캘린더캐릭터)). |

### 적용과 초기화

- **미리보기와 취소**: 조절 중인 테마와 미니 창 캐릭터 크기·표시·위치는 미니 창에 미리 반영됩니다. `취소`나 패널 오른쪽 위 `X`(별도 `설정` 창을 닫는 경우 포함)를 누르면 열기 전 값으로 되돌리며, 미리보기 중 초기화된 캐릭터의 드래그 위치도 복원합니다. `Esc`는 `취소`와 같습니다(단축키 입력 칸에서는 입력만 취소).
- **저장해야 적용되는 항목**: 미리보기가 없는 항목(`모든 창 위에 표시`, D-day 표시, `넘김 애니메이션`, 단축키, `Windows 시작`)과 최종 확정은 `저장`을 눌러야 적용됩니다.
- **직접 바꾼 항목만 반영**: `미니 창에 캐릭터 표시`와 `미니 창 캐릭터 크기`는 그 설정 세션에서 직접 바꾼 경우에만 저장 때 반영되므로, 그 사이 `캐릭터 설정`에서 바꾼 값을 덮어쓰지 않습니다.
- **`초기화`**: 누르면 `정말 초기화`로 바뀌고 한 번 더 눌러야 합니다. 다음 항목을 처음 값으로 되돌립니다.
  - 테마·색상·투명도·글자 크기, 캐릭터 크기와 위치(끌어 둔 캐릭터 위치는 기본 배치로)
  - `모든 창 위에 표시`(끔), `미니 창에 캐릭터 표시`(켬), `일정 블록에 D-day 표시 (미니 창)`(켬), `넘김 애니메이션 (미니 창)`(`효과 1 · 위로 넘기기`), `단축키로 맨 앞에 띄우기`(켬, `Ctrl+G`)
  - `저장`해야 적용되고 `취소`하면 되돌아가며, `Windows 시작`은 바꾸지 않습니다.
- `구글 연동` 칸은 `저장`/`취소`/`초기화`와 상관없이 바로 적용됩니다.
- `연락 · 알림`의 마감 알림, 음악 창의 재생 방식에도 각각 `초기화`가 있습니다. 연동 정보와 플레이리스트는 지우지 않습니다.
- **스위치와 조절 바 모양**:
  - 설정의 모든 켜기/끄기 항목(`모든 창 위에 표시 (일정 창·미니 창)`, `일정 블록에 D-day 표시 (미니 창)`, `단축키로 맨 앞에 띄우기`, `미니 창에 캐릭터 표시`, `Windows 시작`, 구글 연동의 두 스위치)은 회색 OFF / 초록 ON 알약 모양의 ON/OFF 스위치입니다.
  - 조절 바는 얇은 둥근 트랙과 흰색 원형 손잡이이며, 마우스 휠로는 음량 바와 재생 위치 바만 움직입니다. 크기·위치·투명도 같은 설정 바는 휠에 반응하지 않아(의도치 않은 변경 방지) 그 위에서 휠을 굴리면 창이 스크롤됩니다.
  - 스크롤바는 화살표 없는 얇은 둥근 막대이며 마우스를 올리면 조금 굵고 진해집니다.

### 테마

테마는 하나이며 원본 일정 창, 미니 창, 보조 창(`설정`, `캐릭터 선택`, `캐릭터 설정`, `연락 · 알림`, `음악`)에 함께 적용됩니다. 설정의 `테마`나 미니 창 머리띠의 스타일 드롭다운에서 고르며, 열려 있는 창도 바로 바뀝니다. 테마를 고르면 색상 버튼으로 바꿨던 색도 그 테마의 기본 색으로 돌아가므로 색은 테마를 고른 뒤에 바꿉니다.

- **Light**(기본), **Dark**, **Blue**, **Pink**: 각각 밝은 라일락, 어두운 남색, 파랑, 분홍 계열입니다.
- **Modern**: 흑백 테마입니다. 미니 달력은 밝은 회색 바탕에 흰색 날짜 칸과 검은 테두리·글자를 쓰고, 머리띠만 검정 바탕에 흰색 글자·버튼입니다. 요일 글자는 평일 검정, 토요일 파랑, 일요일·공휴일 빨강으로 구분합니다. 원본 일정 창과 보조 창도 흰색·회색 바탕에 검정 강조로 통일됩니다.

### 단축키로 맨 앞에 띄우기

- 기본 `Ctrl+G`입니다. 어느 앱을 쓰고 있든 누르면 원본 일정 창(미니 모드면 미니 창)이 모든 창 위로 한 번 올라오고, 숨겨 둔 창도 다시 나타납니다. 위에 고정되지는 않아서 다른 창을 누르면 평소처럼 그 아래로 내려갑니다(`모든 창 위에 표시` 설정은 그대로).
- 설정의 `단축키로 맨 앞에 띄우기` 스위치로 켜고 끕니다. 그 아래 칸을 누른 뒤 새 조합을 누르면 단축키가 바뀝니다(`Esc`는 입력 취소). `F1`~`F24`는 단독으로도 쓸 수 있고, 그 밖의 키(영문·숫자·방향키·`Space`·`Home`/`End`·`Insert`/`Delete`·`PageUp`/`PageDown` 등)는 `Ctrl`·`Alt`·`Win` 중 하나와 함께 눌러야 합니다. `Ctrl+G로` 버튼은 기본값으로 되돌립니다. `저장`할 때 적용됩니다.
- 다른 프로그램이 이미 같은 단축키를 전역으로 쓰고 있으면 등록되지 않고, 설정 칸에 안내가 나오며 `저장`할 때도 경고합니다. 등록된 동안에는 다른 앱의 같은 단축키(예: 브라우저의 `Ctrl+G` 다음 찾기) 대신 이 동작이 실행됩니다.

## 구글 연동 (캘린더·캐릭터)

설정 패널 아래쪽 `구글 연동` 칸에서 먼저 `구글 로그인`을 누르고, 그다음 `구글 캘린더 연동`과 `캐릭터도 구글 드라이브에 보관` ON/OFF 스위치를 각각 켭니다. 로그인하지 않은 동안 두 스위치는 OFF로 잠겨 있고 로그인만으로는 아무것도 켜지지 않습니다(둘 다 기본 OFF). 각 스위치 아래 상태 줄에는 `꺼짐`, `동기화 중…`, `연동됨 · 마지막 동기화 …` 또는 오류 이유가 표시되고, 스위치를 하나라도 켜 두면 `지금 동기화` 버튼도 나타납니다.

### 로그인과 로그아웃

- 가운데의 `구글 로그인` 버튼을 누르면 브라우저에 구글 로그인이 열립니다. 로그인하고 권한(캘린더 일정, 이 앱이 만든 드라이브 파일)을 허용하면 브라우저에 “구글 캘린더 연동이 끝났습니다.”가 표시되고 설정 칸에 계정이 나옵니다. 로그인 중에는 버튼이 `로그인 취소`로 바뀌어 언제든 취소할 수 있고, 5분 안에 끝내지 않으면 실패 안내가 뜹니다.
- 로그인 뒤 버튼은 `로그아웃`으로 바뀌고 누르면 확인을 묻습니다. 로그아웃은 구글에 연결 권한 해제를 요청하고 이 PC의 로그인 정보를 지우며 두 스위치를 OFF로 돌립니다. 앱·구글 캘린더·드라이브의 일정과 캐릭터는 지우지 않습니다. 같은 계정으로 다시 로그인하면 스위치를 켤 때 이어서 맞추고, 다른 계정으로 로그인하면 이 PC의 일정과 캐릭터를 그 계정에 새로 올립니다.
- 로그인은 PC마다 따로 합니다. 로그인 정보(갱신 토큰)는 다른 연동 키처럼 Windows 계정으로 암호화해 `schedules.json`에 저장합니다.
- 다른 PC나 다른 Windows 계정에서 복사된 로그인 정보는 이 PC에서 읽을 수 없으므로 로그아웃 상태가 되며 다시 로그인해야 합니다. 계정 이메일을 읽지 못해도 연결을 끊거나 다른 계정으로 취급하지 않습니다.

### 일정 동기화 규칙

| 항목 | 동작 |
| --- | --- |
| 앱 → 구글 | 앱의 일정이 구글 기본 캘린더에 추가됩니다(날짜가 30일보다 더 지난 완료 일정은 올리지 않습니다). 시간이 없는 일정은 종일 일정, 시간이 있는 일정은 그 시각부터 1시간짜리 일정이 됩니다. |
| 구글 → 앱 | 오늘 기준 30일 전부터 2년 뒤까지의 일반 일정을 가져옵니다. 반복 일정은 오늘부터 8주 안의 날짜만 날짜별로 하나씩 가져오고, 여러 날에 걸친 일정은 시작 날짜에 한 번 가져옵니다. 구글에서 온 일정은 원래 길이를 유지합니다. |
| 맞추는 내용 | 제목·날짜·시간·완료 여부입니다. 완료 여부는 구글 일정의 보이지 않는 개인 속성으로 저장하고, 카드 색상은 이 PC에만 둡니다. |
| 수정 | 한쪽에서 고친 내용이 다른 쪽에 반영됩니다. 같은 일정을 양쪽에서 모두 고쳤으면 이 PC의 내용이 이깁니다. 위젯에서는 바꾼 항목(제목·날짜/시간·완료)만 구글에 보내므로 구글에서 늘린 길이·설명·참석자는 그대로입니다. 시간을 새로 넣으면 1시간, 시간을 빼면 하루 일정이 됩니다. |
| 삭제 | 자동으로 지우지 않습니다. TODO 목록이나 미니 창에서 일정을 직접 삭제했을 때만 처리하며, 위젯이 만든 참석자 없는 일정만 구글 캘린더에서도 삭제합니다. 자세한 규칙은 아래 `삭제 규칙`을 봅니다. |
| 시점 | 스위치를 켤 때, 앱을 시작할 때, 5분마다, 일정을 추가·수정·삭제하고 몇 초 뒤(동기화하는 동안 고친 일정은 그 동기화가 끝나고 몇 초 뒤), `지금 동기화`를 누를 때 맞춥니다. 실패했을 때의 재시도 간격은 [오류 안내](#오류-안내)를 봅니다. |

- **읽는 방식**: 바뀐 것이 없으면 파일을 다시 쓰거나 목록을 다시 그리지 않습니다. 평소에는 지난번에 목록을 읽기 시작한 시각(UTC) 이후 구글에서 바뀐 일정만 읽고(PC와 구글의 시계 차이를 감안해 10분 더 앞에서부터), 앱 시작 때와 하루 한 번 전체를 읽습니다. 읽기 시작 시각의 기록이 없거나 PC 시계보다 앞서 있으면(시계를 되돌렸을 때) 전체를 읽습니다. 동기화가 오래 걸리거나 그사이 시계·시간대(서머타임)가 바뀌어도 구글에서 고친 일정을 놓치지 않습니다.
- **올리는 양**: 새 일정은 한 번에 최대 100개까지 조금씩 올리고 나머지는 몇 초 뒤 이어서 올리며, 구글이 요청 한도를 알리면 알려 준 시간(최대 1시간)만큼 쉽니다.
- **구글이 받지 않는 일정**: 구글이 받지 않는 일정(잘못된 데이터, 고칠 권한이 없는 일정 등)은 그 일정만 건너뛰고 고치기 전에는 다시 보내지 않으며, 상태 줄에 `구글이 받지 않은 일정 n개 (고치면 다시 보냅니다)`로 표시합니다.
- **가져오는 범위**:
  - 이전 버전이 가져온 8주 뒤의 반복 날짜는 목록에서 빠졌다가(구글에서는 지우지 않습니다) 8주 전이 되면 다시 들어오며, 색을 바꾸거나 위젯에서 고친 것은 남습니다.
  - 30일 전~2년 뒤 범위 밖으로 옮겨진 일정은 위젯에 예전 날짜로 남습니다. 30일보다 오래된 날짜의 일정은 구글에서 바뀌어도 다시 가져오지 않습니다(위젯에서 고치면 구글로 보냅니다).
- **삭제 규칙**:
  - 참석자가 있는 일정(공유 회의·초대받은 일정)과 구글 캘린더에서 만든 일정은 위젯에서만 사라지고 구글에는 그대로 남으며 다시 들어오지 않습니다.
  - 삭제 확인(TODO 창)과 `정말 삭제` 대기(미니 창)에서 그 일정이 어느 쪽인지 `구글 캘린더에서도 삭제됩니다.` 또는 `구글 캘린더에는 남습니다.`로 알려 줍니다. 연동을 꺼 둔 동안 이 앱이 만든 일정을 지우면 `구글 캘린더 연동을 다시 켜면 구글에서도 삭제됩니다.`로 알리고, 연동을 다시 켜면 구글에서도 지웁니다.
  - 이번 동기화에서 읽지 않은 일정(읽는 기간 밖이거나 지난번 이후 바뀌지 않은 일정)은 구글에서 지우기 전에 한 번 확인해, 그사이 참석자가 생겼거나 반복 일정으로 바뀌었으면 지우지 않고 위젯에서만 뺍니다. 그사이 구글에서 이미 지워졌다면 아무것도 하지 않습니다.
  - 업데이트 전에 연결된 일정은 첫 동기화 때 한 번 판정합니다. 이전 버전이 이 PC에서 만들어 구글에 올린 일정만 위젯이 만든 것으로 보고(읽는 기간 밖이라 이번에 읽지 않은 일정도 포함), 구글에서 가져온 일정은 이전 버전에서 완료를 체크했더라도 구글 캘린더에서 만든 일정으로 봅니다. 첫 동기화 전에 삭제한 일정은 구글에 남습니다.
  - 구글에서 지운 일정은 앱에 그대로 남고, 앱에서 다시 고치면 구글에 다시 추가됩니다.

### 캐릭터 보관 (구글 드라이브)

`캐릭터도 구글 드라이브에 보관`(기본 OFF)을 켜면 가져온 캐릭터(기본 캐릭터 제외)를 구글 드라이브의 `ScheduleWidget 캐릭터` 폴더에 캐릭터마다 `.zip` 하나로 올리고, 같은 계정으로 로그인한 다른 PC의 캐릭터를 받아 옵니다.

- 이 PC에 같은 이름의 캐릭터가 이미 있으면(기본 캐릭터 포함) 받지 않고, 드라이브에 같은 이름이 있으면 올리지 않습니다.
- 삭제는 직접 삭제한 것만 전달합니다. `캐릭터 선택` 창에서 `캐릭터 삭제`한 캐릭터만 드라이브에서도 지우고, 드라이브에서 지운 캐릭터는 이 PC에 남고 다시 올리지 않습니다. 이 PC에 없는 캐릭터(`Pet` 폴더가 지워졌거나 새 PC)는 지운 것이 아니라 다시 받아 옵니다. 받지 못한 파일은 드라이브에서 바뀔 때까지 다시 받지 않고, 실패한 개수는 상태 줄에 표시합니다.
- 예전 버전은 지운 기록을 남기지 않았으므로, 업데이트 후 첫 캐릭터 동기화 때 한 번은 이전 버전에서 지운 캐릭터(동기화한 적이 있는데 이 PC에 폴더가 없는 캐릭터)도 드라이브에서 지웁니다. 이 PC에 가져온 캐릭터가 하나도 없으면(`Pet` 폴더가 지워졌거나 새 PC) 아무것도 지우지 않고 다시 받아 옵니다.
- 캐릭터를 가져오거나 삭제하면 몇 초 뒤, 그리고 일정 동기화 때마다 함께 맞춥니다. 앱은 자기가 만든 파일만 볼 수 있는 `drive.file` 권한만 씁니다.

### 오류 안내

- 인터넷이 끊기는 등 동기화가 실패하면 상태 줄에 이유를 보여 주고 30초 → 2분 → 5분 간격으로 다시 시도합니다(`지금 동기화`는 바로 시도). 캐릭터 보관의 문제는 일정 동기화와 따로 표시되며 일정 동기화를 막지 않습니다.
- Google Cloud 프로젝트에서 API가 꺼져 있으면 꺼진 API 이름(`Google Calendar API` 또는 `Google Drive API`)을 알려 줍니다. 콘솔의 `API 및 서비스 → 라이브러리`에서 사용 설정한 뒤 몇 분 후 다시 동기화합니다.
- 로그인이 만료되면(권한 해제 등) 다시 로그인하라는 안내가 나옵니다. `구글 로그인`을 다시 누르면 켜 두었던 스위치가 그대로 이어집니다.
- 권한이 모자라면 어떤 권한이 필요한지 알려 줍니다. 예전에 캘린더 권한만으로 로그인했다면 캐릭터 보관 상태 줄에 `캐릭터 보관은 구글 드라이브 권한이 필요합니다.`가, 구글 로그인 화면에서 캘린더 권한을 허용하지 않았다면 일정 동기화 상태 줄에 `구글 캘린더 연동은 캘린더 권한이 필요합니다.`가 나옵니다. 로그아웃 후 다시 로그인해 그 권한을 허용하면 됩니다.

### 구글 캘린더 연동 준비 (앱을 만드는 사람이 한 번)

구글은 로그인 창을 여는 모든 앱에 OAuth 클라이언트 등록을 요구합니다. 한 번 등록해 앱에 넣으면 사용자는 로그인만 하면 됩니다. 아래 화면 구성은 구글이 바꿀 수 있으니 콘솔의 안내가 다르면 콘솔을 따릅니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들고 `API 및 서비스 → 라이브러리`에서 **Google Calendar API**와 **Google Drive API**를 사용 설정합니다.
2. `OAuth 동의 화면`(Google 인증 플랫폼)에서 앱 이름·지원 이메일을 입력하고 대상을 **외부**로 정한 뒤, 데이터 액세스(범위)에 `.../auth/calendar.events`와 `.../auth/drive.file`을 추가합니다. 로그인한 계정을 표시하려고 `email` 범위도 함께 요청합니다.
3. `클라이언트 → 클라이언트 만들기`에서 유형을 **데스크톱 앱**으로 만들고 JSON을 내려받습니다. ‘웹 애플리케이션’ 유형의 JSON은 `google_client.json`이나 로그인 안내 창으로는 받지 않습니다.
4. 앱에 내장합니다(배포용, 권장): `powershell -ExecutionPolicy Bypass -File tools\Protect-GoogleClient.ps1 -Json <받은 JSON>`을 실행하면 JSON을 AES로 암호화한 `ScheduleWidget\google_client.bin`이 만들어지고(`-Out <파일>`로 저장 위치를 바꿀 수 있습니다), 빌드할 때 `ScheduleWidget.exe` 안에 리소스로 들어갑니다. 원본 JSON은 프로젝트에 두지 말고 따로 보관합니다(`ScheduleWidget/google_client.json`과 `client_secret_*.json`은 `.gitignore`에 등록되어 있음).
5. 사용 범위를 정합니다.
   - 본인이나 소수만 쓰면 동의 화면의 게시 상태를 `테스트`로 두고 **테스트 사용자**에 계정을 등록합니다. 테스트 상태에서는 등록한 계정만 로그인할 수 있고 7일마다 다시 로그인해야 합니다.
   - 여러 사람에게 배포하려면 **프로덕션으로 게시**합니다. 게시하려면 앱 이름, 지원 이메일, 앱 홈페이지 URL, 개인정보처리방침 URL을 입력해야 합니다. 저장소의 [`PRIVACY.md`](PRIVACY.md)가 개인정보처리방침 문안이므로, 웹에 게시한 주소를 넣습니다.
   - 구글 검수를 받지 않은 앱은 로그인할 때 “Google에서 확인하지 않은 앱” 경고가 나오며 `고급 → (앱 이름)(으)로 이동`을 눌러 진행합니다. 이 상태로는 최대 100명까지 쓸 수 있습니다. 이 등록은 모두 무료입니다.

앱이 OAuth 클라이언트를 찾는 순서는 다음과 같으며, 앞의 둘이 내장 클라이언트보다 먼저 쓰입니다.

1. `ScheduleWidget.exe` 옆의 `google_client.json`
2. `%LocalAppData%\ScheduleWidget\google_client.json`(이 PC에만 저장된 파일)
3. exe에 내장된 `google_client.bin`

세 곳 모두 없으면 `구글 로그인`을 누를 때 안내 창이 뜹니다. `예`를 누르고 내려받은 클라이언트 JSON을 고르면 2번 위치에 저장하고 바로 로그인하며, `아니요`는 클라이언트를 만드는 콘솔 페이지를 엽니다.

내장 암호화는 클라이언트 ID가 exe나 배포 폴더에서 그대로 읽히지 않게 가리는 용도일 뿐입니다. 디컴파일하면 꺼낼 수 있고 클라이언트 ID는 로그인 때 브라우저 주소에도 보입니다. 구글도 데스크톱 앱의 클라이언트 보안 비밀을 비밀로 취급하지 않으며, 로그인 보안은 PKCE와 사용자의 허용(동의)으로 지켜집니다.

## 창 표시 방식

- 원본 일정 창과 미니 창은 Windows 바탕화면 호스트(`WorkerW`/`Progman`)에 연결되어 `Win + D`를 눌러도 남습니다.
- 기본값에서는 좌클릭이나 우클릭으로 위젯을 누르면 다른 앱 위로 올라오고, 다른 앱을 누르면 뒤로 갑니다. 트레이의 `열기`와 단축키도 가려진 창을 앞으로 가져옵니다.
- `모든 창 위에 표시 (일정 창·미니 창)`를 켜면 두 창을 항상 위에 고정하며 설정값을 저장합니다.
- 보조 창(`캐릭터 선택`, `캐릭터 설정`, `연락 · 알림`, `음악`, 미니 창에서 여는 `설정`)은 작업 표시줄에 나타나지 않고 제목 표시줄·아이콘 없이 표시됩니다. 오른쪽 위 `X`로 닫고, 빈 곳을 끌어 옮기며, 가장자리를 끌어 크기를 바꿉니다(드롭다운·슬라이더·입력칸·버튼 위에서 누른 것은 그 조작에 쓰입니다). Windows 11에서는 모서리가 살짝 둥글게 표시됩니다. 확인 메시지와 파일 선택 창은 Windows 기본 대화상자를 그대로 사용합니다. 실행 파일과 창은 트레이와 같은 달력 아이콘을 사용합니다.
- 원본 일정 창과 미니 창은 디스플레이 구성이나 DPI가 바뀌면(모니터 연결·배율 변경 등) 바탕화면 호스트를 다시 찾아 붙고, 현재 작업 영역 밖으로 나가지 않도록 위치를 보정합니다. 창을 다른 모니터로 끌어 옮긴 직후에도 마우스를 붙잡아 두지 않아, 옮긴 뒤의 클릭이 정상적으로 동작합니다.
- 탐색기(Explorer)가 다시 시작되어 바탕화면 호스트가 바뀌어도 보이는 창을 다시 붙이고, 숨겨 둔 창은 다시 표시할 때 붙입니다.
- 캐릭터 화면·`캐릭터 선택`·YouTube 플레이어(WebView2)는 브라우저 탭처럼 쓰이지 않도록 브라우저 단축키(`F5`, `Ctrl+P` 등)와 `Ctrl`+휠 확대/축소가 꺼져 있고, 릴리스 빌드에서는 개발자 도구(`F12`)도 꺼져 있습니다.

## 자동 시작

설정의 `Windows 시작`(기본 켜짐)으로 사용자별 레지스트리 항목 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\ScheduleWidget`을 켜고 끕니다. 앱을 시작할 때마다 설정값에 맞춰 항목을 다시 맞추고, 키가 없으면 만들며 변경 결과를 다시 확인합니다. 실패하면 경고를 표시하지만 앱은 계속 실행됩니다.

## 모니터별 위치

원본 일정 창 상단의 모니터 아이콘에서 연결된 모니터를 선택합니다. 현재 모니터의 위치를 먼저 저장한 뒤, 선택한 모니터에 저장된 위치가 있으면 복원하고 없으면 작업 영역 중앙에 놓습니다. 위치와 크기는 Windows 디스플레이 장치 이름(`\\.\DISPLAY1` 등)별로 저장됩니다.

미니 창은 모니터별 슬롯 대신 달력 보드의 화면 위치와 크기를 저장하며, 다시 열 때 현재 작업 영역 안으로 보정합니다.

- `MiniBoard`가 없는 이전 데이터는 `MiniPosition`, 캐릭터 방향·크기·간격, 음악 막대 표시 여부로 보드 영역을 계산해 이어서 사용하며 다음 위치 저장 때 새 형식도 기록합니다.

- 다른 프로그램이 `schedules.json`(또는 그 백업)을 열고 있어 읽을 수 없으면 손상 파일로 보지 않습니다(옮기거나 백업으로 바꾸지 않음). 2초 동안 기다린 뒤 `일정 파일을 열 수 없습니다(다른 프로그램이 사용 중일 수 있습니다). 잠시 후 다시 실행해 주세요.`와 파일 경로, `앱을 종료합니다. 일정 파일은 바꾸지 않았습니다.`를 알리고 아무것도 저장하지 않은 채 종료합니다(빈 데이터로 실행되어 원래 파일을 덮어쓰지 않도록). 저장 폴더에 접근할 수 없어 읽지 못할 때도 같은 방식으로 종료합니다.
- 실행 파일 옆의 구버전 `schedules.json`은 새 파일과 백업이 모두 없을 때만 이전합니다. 새 파일을 다시 읽어 확인한 뒤에만 구버전 파일 삭제를 시도합니다.
- 일정 ID가 없거나 중복된 이전 데이터는 로드·저장 시 새 ID로 보정합니다. 미니 표시 일수, 캐릭터 크기·위치, 음량 등 범위를 벗어난 값도 코드의 허용 범위로 보정합니다.
- ‘2026-9-3’처럼 다르게 쓰인 날짜는 `2026-09-03`으로 저장됩니다.

### 삭제

완전히 지우려면 설정에서 `Windows 시작`을 끄고 `저장`(자동 시작 항목 삭제)한 뒤 앱 폴더와 `%LocalAppData%\ScheduleWidget` 폴더를 삭제합니다. 구글 연동을 썼다면 먼저 `로그아웃`으로 연결 권한을 해제합니다.

### 개인정보와 외부 통신

개발자의 서버는 없고 개발자에게 전송되는 정보도 없습니다. 일정과 설정은 위 파일에만 저장됩니다. 네트워크 통신은 사용자가 쓰는 기능의 서비스로만 나갑니다. 구글 연동(로그인·캘린더·드라이브), 텔레그램·카카오톡 전송, YouTube(제목·재생목록 조회와 임베디드 플레이어 재생)입니다. 각 서비스가 쓰는 정보와 연결 해제 방법은 저장소의 [`PRIVACY.md`](PRIVACY.md)에 구글, 텔레그램·카카오톡, YouTube 순으로 정리되어 있습니다.

## 빌드와 배포

Visual Studio에서 NuGet 패키지를 복원해 빌드하거나, MSBuild가 PATH에 있는 개발자 PowerShell에서 다음 명령을 실행합니다.

```powershell
msbuild ScheduleWidget.sln -restore /p:RestorePackagesConfig=true /p:Configuration=Release /p:Platform='Any CPU'
```

- 실행 파일은 `ScheduleWidget\bin\Release\ScheduleWidget.exe`입니다. 앱이 실행 중이면 파일 잠금으로 빌드가 실패할 수 있으므로 트레이에서 먼저 종료합니다.
- `ScheduleWidget\google_client.bin`이 있으면 빌드가 `ScheduleWidget.exe`의 리소스로 넣습니다. 그러므로 배포 폴더에 `google_client.json`이나 `Pet` 폴더는 필요 없습니다. 반대로 프로젝트 폴더에 `google_client.json`이 있으면 빌드가 출력 폴더로 복사하고 앱은 그 파일을 내장 클라이언트보다 먼저 쓰므로, 배포용 빌드에서는 두지 않습니다.
- 배포할 때는 `ScheduleWidget.exe`, `ScheduleWidget.exe.config`, `ScheduleWidget.Updater.exe`, Newtonsoft.Json·WebView2 DLL, `Player`, `DefaultPets`, `runtimes`가 포함된 `ScheduleWidget\bin\Release` 폴더 전체를 옮깁니다. 실행 파일만 따로 복사하면 동작하지 않습니다. `*.pdb`, `*.xml`은 필요 없습니다.
- 업데이트 저장소는 `Services\UpdateClient.cs`의 `GitHubRepository`이며, 가져온 설정은 `rnrdus5642/ScheduleWidget`입니다. 앱은 `Services\UpdatePublicKey.cs`의 공개키로 업데이트를 검증합니다. `tools\Publish-Update.ps1`로 새 업데이트를 발행하려면 이 공개키와 일치하는 개인키가 `%USERPROFILE%\.schedulewidget\update-signing-key.xml`에 있어야 합니다. 개인키는 저장소에 포함되지 않습니다.

## 검증

기능 이식 후 추가한 오프라인 검증 하네스입니다. 가져온 폴더에는 이전 README가 설명하던 테스트 코드가 없어, 아래 범위부터 새로 검증합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\Run-Checks.ps1
```

- MSBuild를 PATH 또는 Visual Studio 설치에서 찾고 NuGet 패키지를 복원한 뒤 앱·업데이터·검사기를 `.work\checks\<실행 ID>\app`에 Release로 빌드합니다. 검사 결과는 같은 실행 폴더의 `checks.log`에 남깁니다.
- 데이터 저장·복구 검사는 실행 폴더의 `data`만 사용합니다. 실제 일정 파일·자동 시작 레지스트리·계정 토큰은 변경하지 않습니다. 기존 앱을 실행한 상태에서도 검사할 수 있습니다.
- 검증 범위: 구버전 데이터 이전과 일정 ID, 추가 설정 보존, 불필요한 저장 방지, 손상 파일 백업 복구, 사용 중인 파일 보호, 여러 날 일정, 시간·알림 규칙, YouTube 주소 판별, 구글 일정 변경·삭제 규칙, 드라이브 캐릭터 삭제 규칙, 기본 캐릭터와 배포 파일, 업데이트 서명 변조 거부, 단축키, 목록의 옆 배치·화면 경계·배율 좌표 처리, 주요 창 6개의 WPF 리소스·레이아웃 생성, 목록 요청과 닫기 버튼이 달력을 종료하지 않는 동작.
- 창 검사는 실제 창을 표시하거나 앱의 시작 이벤트를 실행하지 않습니다. WebView2 렌더링, 음악 재생, 바탕화면·DPI 동작, 구글 로그인·동기화, 실제 알림 발송은 별도 실행 검증이 필요합니다. 검사 중에는 외부 서비스에 요청하거나 메시지를 보내지 않습니다. NuGet 복원에는 인터넷이 필요할 수 있습니다.
- 검사 프로세스의 제한 시간은 기본 120초이며 `-TimeoutSeconds`로 바꿀 수 있습니다. 실행 결과 폴더는 자동 삭제하지 않습니다.
