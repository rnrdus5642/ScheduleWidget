\# 📅 ScheduleWidget



Windows 바탕화면에 고정되어 표시되는 \*\*D-day 일정 위젯\*\*입니다.

일정을 간단하게 추가하고, 남은 날짜를 직관적으로 확인할 수 있도록 설계되었습니다.



WinAPI와 WPF를 활용하여 일반 프로그램이 아닌 \*\*바탕화면 위젯처럼 동작\*\*하는 것이 특징입니다.



---



\## ✨ 주요 기능



\### 🖥️ 바탕화면 위젯



\* Windows 바탕화면(SysListView32)에 직접 부착

\* Alt + Tab, 작업 표시줄에 표시되지 않음

\* 항상 바탕화면에 자연스럽게 고정



\### 📆 일정 / D-day 관리



\* 일정 제목 + 날짜(연 / 월 / 일) 입력

\* D-day 자동 계산



&nbsp; \* 오늘: `D-day`

&nbsp; \* 미래: `D-n`

&nbsp; \* 과거: `D+n`

\* 날짜를 `MM.dd (요일)` 형식으로 표시

\* 우클릭 메뉴를 통한 일정 삭제 지원



\### 🔃 자동 정렬



\* D-day 기준 자동 정렬



&nbsp; \* 오늘 → 미래 → 과거 순

\* 상태에 따라 색상으로 구분



&nbsp; \* 오늘: 파란색

&nbsp; \* 미래: 검정

&nbsp; \* 과거: 빨간색



\### 💾 상태 저장



\* 일정, 창 위치, 창 크기를 JSON 파일로 저장

\* 프로그램 재실행 시 마지막 상태 자동 복원



\### 🖱️ 이동 / 크기 조절 모드



\* 상단 토글 스위치 제공



&nbsp; \* OFF: 고정 모드 (이동/크기 변경 불가)

&nbsp; \* ON: 자유 모드 (드래그 이동 + 크기 조절 가능)



\### 🔔 시스템 트레이 연동



\* 실행 시 시스템 트레이 아이콘 생성

\* 트레이 메뉴



&nbsp; \* 열기: 위젯 다시 표시

&nbsp; \* 종료: 프로그램 완전 종료

\* 창 닫기 버튼으로는 종료되지 않음



\### 🚀 윈도우 시작 시 자동 실행



\* 레지스트리 등록을 통해

\* Windows 부팅 시 자동 실행



---



\## 🛠️ 사용 기술



\* \*\*C# / .NET (WPF)\*\*

\* \*\*WinAPI (user32.dll)\*\*



&nbsp; \* FindWindow / SetParent

&nbsp; \* SetWindowLong (Alt+Tab 숨김 처리)

\* \*\*Newtonsoft.Json\*\*

\* \*\*Windows Registry\*\* (자동 실행)



---



\## 참고 사항



\* 종료하려면 반드시 \*\*시스템 트레이 → 종료\*\*를 사용하세요.

\* 데이터는 `%LocalAppData%\ScheduleWidget\schedules.json`에 저장됩니다.

\* 저장할 때 이전 데이터는 `schedules.json.bak`으로 자동 백업됩니다.

\* 이전 버전에서 실행 파일 옆에 저장된 `schedules.json`은 최초 실행 시 자동 이전되며 원본도 보존됩니다.
